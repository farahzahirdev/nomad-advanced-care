# Nomad Therapeutics — Advanced Care Landing Page

Separate campaign landing page for Nomad Therapeutics advertising **Medication Management, Spravato (Esketamine), and TMS** for greater Seattle.

> Related but separate from `nomad-therapeutics` (at-home IM ketamine campaign).

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Features

- Hero + empathy + services (Med Mgmt / Spravato / TMS)
- How it works, Why Nomad, social proof, FAQ
- Embedded 4TMS inquiry form + booking calendar
- Twilio tracking number: (425) 675-8754
- Logo-aligned forest / mint visual system

## Deploy

```bash
npm run build
npm start
```
